# 화현전기 (話現戰記)

**"이야기가 현실로 나타난 전쟁의 기록."**

신화·전설·역사 속 이야기의 영웅들이 현실 대륙에 나타나 벌이는 대규모 난전 거점점령 게임의 MVP 수직 슬라이스입니다. 플레이어는 전장의 유닛 하나에 깃들어(빙의) 직접 싸우고, 나머지 군대는 스스로 판단해 싸웁니다.

플레이어는 언제든 아군 유닛(영웅·검병·궁병) 아무나 하나에 빙의해 조작할 수 있고, 나머지 아군 수십 명과 적 마수 군단은 전부 자율 AI로 움직입니다. 대륙 위 5개 거점(한양·평양·베이징·상하이·교토)을 놓고 부대 단위 난전을 벌입니다.

## 게임 방법

- **목표**: 5개 거점을 모두 점령하면 승리. **영웅이 쓰러지면 패배**.
- **점령**: 적 거점 반경 안의 수비대를 전멸시킨 뒤, 아군이 반경 안에 머무르면 점령 게이지가 차오릅니다(약 5초). 점령 시 아군 병사 5명이 증원됩니다.
- **유닛 전환(빙의)**: 전투는 전부 자율 AI로 돌아가며, 플레이어는 아군 유닛 하나에 빙의해 조작합니다.
  - 아군 유닛을 **탭(모바일) / 클릭(데스크톱)** 하면 그 유닛으로 조작이 전환됩니다.
  - 조작 중인 유닛은 AI가 멈추고 플레이어 입력으로 움직이며, 사거리 안의 적을 자동으로 공격합니다.
  - 발밑의 **노란 선택 링**과 카메라 추적으로 현재 조작 유닛을 확인할 수 있습니다.
  - 조작하지 않는 유닛(빙의를 떠난 영웅 포함)은 즉시 자율 AI로 복귀해 함께 싸웁니다.
  - 조작하던 병사가 죽으면 자동으로 **영웅에게 조작이 복귀**합니다. 데스크톱에서는 **Tab** 키로 언제든 영웅으로 돌아올 수 있습니다.
  - 스킬 "일섬"(주변 원형 AOE)은 **영웅에 빙의 중일 때만** 사용할 수 있습니다(다른 유닛 조작 중엔 버튼이 비활성).
- **조작**
  - 모바일: 화면 **왼쪽**을 드래그하면 그 자리에 플로팅 조이스틱이 생겨 이동, **오른쪽 하단** 원형 버튼으로 스킬. 아군을 짧게 **탭**하면 빙의.
  - 데스크톱: **WASD / 화살표** 이동, **스페이스바** 스킬, 아군 **클릭** 빙의, **Tab** 영웅 복귀.

## 기술 스택

- Phaser 3 + TypeScript + Vite
- 외부 이미지/오디오 에셋 **0개** — 모든 스프라이트(유닛·성채·깃발·데코·이펙트·선택 링)는 Canvas에 픽셀 단위로 그려 런타임에 텍스처로 등록합니다 (`src/gen/spriteGen.ts`).
- Arcade Physics. 80+ 유닛 동시 전투를 위해 그리드 기반 타겟 탐색 + 스태거드 AI 틱(프레임 분산) + 투사체 오브젝트 풀링을 사용합니다.

## 로컬 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173/make/)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## GitHub Pages 배포

이 저장소에는 `.github/workflows/deploy.yml` 이 포함되어 있습니다. `main` 브랜치에 push하면 자동으로 빌드 후 Pages에 배포됩니다.

워크플로의 deploy 잡이 `actions/configure-pages@v4` (`enablement: true`) 로 Pages 사이트를 **자동 생성/활성화**하므로, 저장소 설정에서 별도로 Pages를 켜지 않아도 첫 배포부터 동작합니다.

1. `main` 브랜치에 push (또는 Actions 탭에서 `workflow_dispatch` 로 수동 실행)
2. 배포 완료 후 `https://<사용자명>.github.io/make/` 에서 플레이

> `vite.config.ts` 의 `base: '/make/'` 는 프로젝트 페이지 경로(`/make/`)에 맞춘 값입니다. 저장소 이름이 다르면 이 값을 함께 바꿔야 합니다.

## 프로젝트 구조

```
src/
  main.ts              # Phaser 게임 부트스트랩
  config.ts            # 모든 밸런스 수치 + 탭(빙의) 판정 상수
  gen/spriteGen.ts     # 절차 생성 스프라이트 (유닛·성채·깃발·데코·이펙트·선택 링)
  scenes/
    BootScene.ts       # 텍스처 생성
    TitleScene.ts      # 타이틀 + 시작 버튼
    BattleScene.ts     # 전투 로직 (유닛·AI·거점·승패·유닛 전환)
    UIScene.ts         # HUD·스킬버튼·게이지·승패 오버레이
  units/
    Unit.ts            # 유닛 기반 클래스 (HP바·피격·이동·플레이어 조작)
    Hero.ts            # 영웅 (빙의 조작 + 자율 AI)
    Soldier.ts         # 아군 병사 (검병/궁병, FSM AI + 빙의 조작)
    Monster.ts         # 적 마수 (고블린/오니)
    Projectile.ts      # 화살 투사체 (풀링)
  world/
    MapGen.ts          # 절차 생성 대륙 배경 + 데코 산포
    Stronghold.ts      # 거점(성채·깃발·라벨·점령)
  input/
    FloatingStick.ts   # 모바일 플로팅 조이스틱
```

## 알려진 한계 (이번 슬라이스 범위 밖)

- 사운드, 세이브, 캠페인 없음.
- 아군 거점은 적 습격대의 공격을 받지만, 적에게 **점령당하지는** 않습니다(패배 조건은 영웅 사망만).
- 빙의는 아군 개별 유닛에만 가능하며, 부대 단위 명령(집결·돌격 지정 등)은 없습니다.
