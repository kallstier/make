# 화현전기 (話現戰記)

**"이야기가 현실로 나타난 전쟁의 기록."**

신화·전설·역사 속 이야기의 영웅들이 현실에 나타나 벌이는 게임입니다. **삼국지풍 거점 노드맵** 위에서 부대를 지역으로 이동시켜 영토를 점령해 가는 **턴제 전략층**과, 그 아래에서 벌어지는 **밀집 야전(전투층)**의 2층 구조입니다.

## 게임 루프 (전략맵 → 이동 → 전투 → 점령)

1. **전략맵**: 동아시아 퓨전 세계관의 거점 **10개**(한양·평양·개경·전주·부산·의주·심양·베이징·청두·상하이)가 길(엣지)로 이어진 그래프 지도. 절차 생성 대륙(초원·산맥·강·해안)을 배경으로, 각 거점은 성채 스프라이트 + 도시명 + 소유 표식(아군 파랑 깃발 / 몬스터 점유 지역은 병종 아이콘)으로 그려집니다. 시작 시 **한양**(수도)만 아군이고 나머지 9개는 몬스터(고블린·**산적**·오니 계열, 먼 곳일수록 강하고 일부는 보스 포함)가 점유합니다. 카메라는 드래그 팬 + 휠/핀치 줌(모바일 우선)으로 조작합니다.
2. **이동 예약(턴제)**: 부대 배너를 탭해 선택하면 인접 거점이 강조됩니다. 인접 거점을 탭하면 그 방향으로 **이동 명령이 예약**(화살표 표시)되고, 다시 탭하면 취소됩니다. 부대별로 **한 턴에 한 칸**만 움직입니다.
3. **턴 종료**: 우하단 **[턴 종료]** 버튼으로 예약된 이동을 실행합니다. 아군 소유 거점으로의 이동은 즉시 이루어지고, **적 점유 거점으로 향하면 "○○ 공격!" 확인 팝업**(취소 시 원위치) 후 야전(전투층)으로 진입합니다. 같은 거점을 노린 여러 부대는 **합동 전투**로 함께 참전합니다. 주둔(비이동) 부대는 아군 거점에서 HP 30%·MP 50%를 회복(정비)합니다.
4. **전투 결과 반영**: **승리** 시 거점을 점령(깃발 교체)하고 생존 유닛의 HP/LV/EXP·투항 편입병이 부대에 이월되며 입성합니다. **탈출** 시 탈출 생존자만 이끌고 출발 거점으로 귀환(거점 미점령, 입힌 피해는 수비 편성에 잔존 반영)합니다. **패배**(전멸)는 그 부대 소멸, **영웅 전사는 게임 오버**입니다. 수비 편성도 영속하므로, 승리하지 못해도 소모전이 쌓입니다(전사한 수비병은 다음 공격 때 없음).
5. **승리**: 모든 거점을 점령하면 **천하 통일**(승리 화면 — 총 턴 수·전적).

플레이어는 전투층에서 아군 유닛 하나에 깃들어(빙의) 직접 싸우고, 나머지 병력은 전부 자율 AI로 움직이며, **부대 단위로 전술 명령**을 내립니다. 아군 2개 부대(1부대는 영웅 포함)가 한양에서 출발합니다.

## 전투층 (밀집 야전)

거점 공격 시, 참전 아군 부대와 그 거점의 수비 편성이 평원에서 대형을 이루고 마주 본 뒤 중앙에서 충돌해 서로 뒤엉켜 밀치는 난전을 벌입니다. 편성 데이터는 **전략층 상태(GameState)**에서 공급되며(config의 하드코딩 편성 의존 제거), 전투가 끝나면 결과가 다시 전략층에 반영됩니다.

병력은 **부대(squad)** 단위로 편성됩니다. 각 부대는 검병·궁병·창병(적은 고블린·고블린 궁수·**산적**·오니)으로 구성되며, 선두 유닛 위의 **부대 배너**와 미세한 색조로 소속을 구분합니다. 강력한 거점의 수비대에는 **보스**(**고블린 킹** / **오니 대장**)가 서며, HP·공격력이 대폭 높고 처치 시 경험치 보상이 큽니다.

모든 유닛은 **RPG 스탯 층**(HP·MP·LV·직업)과 **부위별 장비 6슬롯**(무기·투구·상의·하의·장갑·신발)을 가집니다. 최종 스탯 = 직업 기본값 + 레벨 성장 + 장비 보정이며, 피해 계산에 방어력이 반영됩니다(`dmg = max(1, atk - def*0.5)`). 장비에는 발동형 스킬(proc)을 붙일 수 있어, **영웅의 폭열검**은 근접 타격 시 10% 확률로 폭발 마법(AOE)을 일으킵니다.

## 게임 방법

- **목표**: 적을 전멸시키면 승리. **영웅이 쓰러지면 즉시 패배**하고, 아군이 초기 병력의 10% 이하로 줄면 패주(패배)합니다. **모든 아군 부대가 전장을 이탈(탈출)하면 "탈출" 결과**로 끝나며(패배와 구분), 탈출 생존자 명단이 결과에 남아 다음 라운드의 "이전 거점으로 귀환"에 쓰입니다.
- **부대 전술 명령**: 좌상단(상단 요약 아래)에 **부대 탭 2개**(1부대/2부대, 생존 수 표시)와 **명령 버튼 5개**가 있습니다. 탭으로 부대를 고른 뒤 명령을 내립니다. 현재 명령은 하이라이트됩니다.
  - **돌격**(기본): 적을 찾아 자유 교전.
  - **정지**: 제자리 유지. 근접 사거리에 든 적에게만 반격하고 이동하지 않습니다.
  - **이동**: 선택 후 전장의 한 지점을 탭하면(깃발 마커 표시) 부대가 교전을 피하며 그 지점으로 집결하고, 도착하면 자동으로 "정지"로 전환됩니다.
  - **후퇴**: 아군 진입 방향(좌측 라인)으로 물러납니다. 쫓아온 적이 사거리에 들면 싸우면서 후퇴합니다.
  - **탈출**: 부대가 좌측 전장 가장자리로 이탈하며, 가장자리에 닿은 유닛은 전장에서 빠져나갑니다(생존 기록).
  - **빙의 중인 유닛은 부대 명령보다 유저 입력이 우선**합니다(하이브리드 유지). 명령은 부대원 전체에 적용되며, 조작 중 유닛은 입력하는 동안만 명령을 무시하고 손을 떼면 다시 명령을 따릅니다.
  - 데스크톱 단축키: **1·2** 부대 선택, **Q·W·E·R·T** = 돌격·정지·이동·후퇴·탈출.
- **적 보스**: 각 적 무리에 보스(고블린 킹 / 오니 대장)가 한 명씩 있습니다. 머리 위 **보스 마크(왕관)**로 표시되고, 하단 정보창에서 이름이 **빨강으로 강조**되며 `☠ 적장(보스)` 태그가 붙습니다. 보스를 처치하면 **화면 흔들림 + 파편 연출**과 함께 **"적장 격파!" 배너**가 뜹니다.
- **투항(원작 특징)**: 열세에 몰린 적 일반병은 투항할 수 있습니다. 자기 HP가 30% 미만이고 자기 진영 잔존율이 50% 미만이면 낮은 확률로, **보스가 죽으면 그 무리 전원이 즉시 40% 판정 + 이후 상시 확률 10배**로 투항합니다. 투항병은 **백기**를 들고 무기를 내려놓은 채 1초간 멈췄다가 **파랑 계열로 재틴트되어 아군(가장 가까운 부대)으로 편입**되어 이후 아군 명령을 따릅니다. 하단 정보창에 `⚑ 투항병` 태그가 붙고, 상단 아군/적 카운트에 실시간 반영되며, 결과창에 **투항 영입 수**가 집계됩니다.
- **개전**: 양군이 좌·우에서 3~4열 밀집 대형으로 마주 본 뒤(약 2초), 서로를 향해 진군해 중앙에서 충돌합니다. 시작 시 전장 전체가 줌아웃으로 비친 뒤 조작 유닛으로 줌인합니다.
- **밀집 난전**: 전 유닛이 원형 충돌체 + 분리(separation) 스티어링으로 서로 겹치지 않게 밀치며 뒤엉킵니다. 근접 유닛은 사거리에서 멈춰 공격(짧은 런지 + 넉백), 궁병은 후열을 유지하며 근접 적이 붙으면 물러납니다. 타격 시 대미지 숫자·스파크가 뜨고, 쓰러진 유닛은 잠시 시체로 남았다 사라집니다.
- **성장(레벨업)**: 유닛을 처치하면 처치자(아군)가 EXP를 얻고, 일정량을 모으면 **레벨업**합니다. 레벨업 시 HP/MP 일부가 회복되고 스탯이 소폭 오르며, 유닛 위에 **"LV UP!"** 문구가 뜹니다(적은 레벨 고정). 전직은 아직 없습니다(구조만 마련).
- **하단 정보창(2단 구성)**: 화면 하단에 선택 유닛의 정보를 2단으로 표시합니다. **1단**: 얼굴 · 부대·이름 · **LV·직업** · **ATK/DEF** · **HP바** · **MP바(파랑)** · 처치·EXP, 그리고 스킬 장비가 있으면 그 설명 한 줄(예: `폭열검 — 타격 시 10% 폭발`). **2단**: **장비 6슬롯**(아이콘 + 이름, 빈 슬롯은 회색 `-`). 기본은 빙의 중인 유닛을 보여주며, **어떤 유닛이든(적 포함) 탭/클릭하면 그 유닛 정보로 갱신**됩니다(아군 클릭 = 빙의 + 정보, 적 클릭 = 정보만).
- **유닛 전환(빙의) + 하이브리드 조작**:
  - 아군 유닛을 **탭(모바일) / 클릭(데스크톱)** 하면 그 유닛으로 조작이 전환됩니다. 발밑의 **노란 선택 링**과 카메라 추적으로 현재 조작 유닛을 확인합니다.
  - **빙의 중인 유닛도 기본은 AI가 계속 스스로 싸웁니다**(자동 이동 + 자동 공격). **유저가 이동 입력(조이스틱 드래그 / WASD·화살표)을 하는 동안에만** 이동이 수동으로 오버라이드되고, 입력을 멈추면 0.5초 뒤 AI 이동이 재개됩니다. 자동 공격은 수동 이동 중에도 항상 유지됩니다.
  - 영웅도 병사와 같은 교전 AI로 스스로 전장에서 싸웁니다. 조작하던 유닛이 죽으면 자동으로 **영웅에게 조작이 복귀**하며, 데스크톱에서는 **Tab** 키로 언제든 영웅으로 돌아옵니다.
  - 액티브 스킬 "일섬"(주변 원형 AOE)은 **영웅에 빙의 중 + MP가 충분할 때만**(MP 30 소모) 사용할 수 있습니다. MP가 부족하면 버튼이 비활성화됩니다.
  - **폭열검**: 영웅의 기본 무기. 근접 타격 시 10% 확률로 타격 지점에 폭발 마법이 터져 반경 내 적에게 AOE 피해(주황 대미지 숫자) + 화염 이펙트 + 짧은 화면 흔들림을 일으킵니다.
- **조작**
  - 모바일: 화면 **왼쪽**을 드래그하면 플로팅 조이스틱으로 이동, **오른쪽 하단** 버튼으로 스킬, 유닛 **탭**으로 빙의/정보.
  - 데스크톱: **WASD / 화살표** 이동, **스페이스바** 스킬, 유닛 **클릭** 빙의/정보, **Tab** 영웅 복귀.

## 기술 스택

- Phaser 3 + TypeScript + Vite
- 외부 이미지/오디오 에셋 **0개** — 모든 스프라이트(유닛·배너·데코·이펙트·링)는 논리 픽셀 그리드에 손으로 배치한 뒤 실루엣 자동 외곽선 + 명암 2단계로 그려 런타임 텍스처로 등록합니다 (`src/gen/spriteGen.ts`). 유닛마다 걷기 2 + 공격 1 + 시체 1 프레임.
- Arcade Physics. 85+ 유닛 동시 밀집 전투를 위해 그리드 기반 타겟 탐색 + 그리드 기반 분리(separation) 스티어링 + 스태거드 AI 틱(프레임 분산) + 투사체/이펙트 오브젝트 풀링 + HP바 배치 렌더를 사용합니다.

## 로컬 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173/make/)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## GitHub Pages 배포

이 저장소에는 `.github/workflows/deploy.yml` 이 포함되어 있습니다. `main` 브랜치에 push하면 자동으로 빌드 후 Pages에 배포됩니다.

워크플로의 deploy 잡이 `actions/configure-pages@v4` (`enablement: true`) 로 Pages 사이트를 **자동 생성/활성화**하므로, 저장소 설정에서 별도로 Pages를 켜지 않아도 첫 배포부터 동작합니다.

1. `main` 브랜치에 push (또는 Actions 탭에서 `workflow_dispatch` 로 수동 실행)
2. 배포 완료 후 `https://<사용자명>.github.io/make/` 에서 플레이

> `vite.config.ts` 의 `base: '/make/'` 는 프로젝트 페이지 경로(`/make/`)에 맞춘 값입니다. 저장소 이름이 다르면 이 값을 함께 바꿔야 합니다.

## 프로젝트 구조

```
src/
  main.ts              # Phaser 게임 부트스트랩
  config.ts            # 모든 밸런스 수치 + 탭(빙의) 판정 상수
  gen/spriteGen.ts     # 절차 생성 스프라이트 (유닛·배너·데코·이펙트·링·성채·노드 깃발)
  state/
    GameState.ts       # 전략층 상태 (거점 소유/수비·부대 명단·전투 셋업/결과 반영) — 직렬화 가능한 평범한 데이터
  scenes/
    BootScene.ts       # 전략층 초기화 + 부대/수비대 병종 텍스처·성채·깃발 등 전체 텍스처 생성
    TitleScene.ts      # 타이틀 + 시작 버튼 (→ 전략맵)
    StrategyScene.ts   # 거점 노드맵 (성채/길/깃발) + 턴제 부대 이동/점령 + 전투 진입 배선 + 카메라 팬·줌
    BattleScene.ts     # 야전 로직 (전략층 편성 스폰·대형·AI·분리 스티어링·승패·빙의·정보 선택·결과 반영)
    UIScene.ts         # 상단 요약 + 하단 정보창 + 스킬버튼 + 결과 오버레이
  rpg/
    stats.ts           # 최종 스탯 계산 (직업 base + 레벨 성장 + 장비) + EXP 테이블 조회
    items.ts           # 부위별 장비 6슬롯 · 아이템 정의 · 병종 기본 세트 · 스탯 보정 합산
    skills.ts          # 장비 proc 스킬 (폭열검=폭발, 금강저=스턴+넉백) — 범용 { chance, effect } 구조
  units/
    Unit.ts            # 유닛 기반 클래스 (스탯·레벨업·장비·피격/방어·넉백·분리·공용 전투 루틴·하이브리드 조작·전술 명령 인지 전투·투항/보스/탈출 상태)
    Hero.ts            # 영웅 (교전 AI + 빙의 + 일섬 스킬 MP 소모)
    Soldier.ts         # 아군 병사 (검병/궁병/창병)
    Monster.ts         # 적 (고블린/고블린 궁수/산적/오니 + 보스: 고블린 킹/오니 대장, 투항 판정 위임)
    Projectile.ts      # 화살 투사체 (곡사 + 그림자, 풀링)
  world/
    MapGen.ts          # 평원 전장 배경 + 데코 배치 / 전략 노드맵 대륙(초원·산맥·강·해안) 절차 생성
  input/
    FloatingStick.ts   # 모바일 플로팅 조이스틱
```

전략층 상태는 `state/GameState.ts` 한 곳에 모여 있습니다. 거점(`NodeState`: 소유·인접·수비 편성)과 아군 부대(`SquadState`/`UnitState`: 유닛별 HP·MP·LV·EXP·투항 여부)를 **직렬화 가능한 평범한 데이터 구조**로 들고, 전투 진입 시 `buildBattleSetup()`으로 `BattleSetup`(참전 부대 + 수비 편성)을 만들어 `BattleScene`에 넘깁니다. 전투가 끝나면 `BattleResult`(승/패/**탈출** 구분·**생존 유닛 상태**·**수비대 잔존**·영웅 전사 여부)를 `applyBattleResult()`가 소비해 거점 소유/부대 명단/수비 잔존을 갱신합니다. 세이브(직렬화 저장)는 다음 라운드 몫이지만, 상태 구조는 이미 그에 맞춰져 있습니다. 밸런스 수치·부대 전술 명령(`SquadOrder`)·투항 확률(`SURRENDER`)·전술 상수(`TACTICS`)·보스 병종(`BOSS_TYPES`)은 `config.ts` 한 곳에 집약되어 있습니다.

## 알려진 한계 (이번 라운드 범위 밖)

- 전략층은 **테스트용 소규모 지역(거점 10개)**입니다. 세이브(진행 저장), 부대 편성/재편 화면, **타국(적) AI 부대의 능동 이동·반격**은 아직 없습니다(수비대는 제자리에서만 방어). 전략층 상태는 직렬화 가능한 구조라 세이브는 다음 라운드에 얹을 수 있습니다.
- 수비대 영속은 **병력 수(감소분)** 단위입니다. 개별 수비병의 잔여 HP까지 다음 공격으로 이월하지는 않습니다(살아남은 수비병은 다음 전투에서 만피로 재배치되되, 전사한 수는 그대로 빠집니다).
- 사운드, 캠페인/스토리는 아직 없습니다.
- 부대 명령(전투층)은 이동/집결·후퇴·탈출까지 지원하되, 대형 종류 선택(방진/횡대 등)이나 표적 지정 돌격은 아직 없습니다.
- 투항은 적 일반병만 대상이며(보스 제외), 재투항/이탈은 없습니다.
- 장비 착탈/인벤토리 UI와 전직(직업 변경)은 마을 층(예정)의 몫이며, 이번 슬라이스는 기본 장비가 스탯에 반영되고 정보창에 표시되는 데까지입니다. MP 자동 회복은 아직 없습니다.
