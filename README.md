# 화현전기 (話現戰記)

**"이야기가 현실로 나타난 전쟁의 기록."**

신화·전설·역사 속 이야기의 영웅들이 현실에 나타나 벌이는 **밀집 야전** 게임의 수직 슬라이스입니다. 아군 2개 부대(영웅 포함 42명)와 적 2개 무리(45마리)가 평원에서 대형을 이루고 마주 본 뒤, 중앙에서 충돌해 서로 뒤엉켜 밀치는 난전을 벌입니다. 플레이어는 전장의 아군 유닛 하나에 깃들어(빙의) 직접 싸우고, 나머지 병력은 전부 자율 AI로 움직입니다.

병력은 **부대(squad)** 단위로 편성됩니다. 각 부대는 검병·궁병·창병(적은 고블린·고블린 궁수·오니)으로 구성되며, 선두 유닛 위의 **부대 배너**와 미세한 색조로 소속을 구분합니다.

모든 유닛은 **RPG 스탯 층**(HP·MP·LV·직업)과 **부위별 장비 6슬롯**(무기·투구·상의·하의·장갑·신발)을 가집니다. 최종 스탯 = 직업 기본값 + 레벨 성장 + 장비 보정이며, 피해 계산에 방어력이 반영됩니다(`dmg = max(1, atk - def*0.5)`). 장비에는 발동형 스킬(proc)을 붙일 수 있어, **영웅의 폭열검**은 근접 타격 시 10% 확률로 폭발 마법(AOE)을 일으킵니다.

## 게임 방법

- **목표**: 적을 전멸시키면 승리. **영웅이 쓰러지면 즉시 패배**하고, 아군이 초기 병력의 10% 이하로 줄면 패주(패배)합니다.
- **개전**: 양군이 좌·우에서 3~4열 밀집 대형으로 마주 본 뒤(약 2초), 서로를 향해 진군해 중앙에서 충돌합니다. 시작 시 전장 전체가 줌아웃으로 비친 뒤 조작 유닛으로 줌인합니다.
- **밀집 난전**: 전 유닛이 원형 충돌체 + 분리(separation) 스티어링으로 서로 겹치지 않게 밀치며 뒤엉킵니다. 근접 유닛은 사거리에서 멈춰 공격(짧은 런지 + 넉백), 궁병은 후열을 유지하며 근접 적이 붙으면 물러납니다. 타격 시 대미지 숫자·스파크가 뜨고, 쓰러진 유닛은 잠시 시체로 남았다 사라집니다.
- **성장(레벨업)**: 유닛을 처치하면 처치자(아군)가 EXP를 얻고, 일정량을 모으면 **레벨업**합니다. 레벨업 시 HP/MP 일부가 회복되고 스탯이 소폭 오르며, 유닛 위에 **"LV UP!"** 문구가 뜹니다(적은 레벨 고정). 전직은 아직 없습니다(구조만 마련).
- **하단 정보창(2단 구성)**: 화면 하단에 선택 유닛의 정보를 2단으로 표시합니다. **1단**: 얼굴 · 부대·이름 · **LV·직업** · **ATK/DEF** · **HP바** · **MP바(파랑)** · 처치·EXP, 그리고 스킬 장비가 있으면 그 설명 한 줄(예: `폭열검 — 타격 시 10% 폭발`). **2단**: **장비 6슬롯**(아이콘 + 이름, 빈 슬롯은 회색 `-`). 기본은 빙의 중인 유닛을 보여주며, **어떤 유닛이든(적 포함) 탭/클릭하면 그 유닛 정보로 갱신**됩니다(아군 클릭 = 빙의 + 정보, 적 클릭 = 정보만).
- **유닛 전환(빙의) + 하이브리드 조작**:
  - 아군 유닛을 **탭(모바일) / 클릭(데스크톱)** 하면 그 유닛으로 조작이 전환됩니다. 발밑의 **노란 선택 링**과 카메라 추적으로 현재 조작 유닛을 확인합니다.
  - **빙의 중인 유닛도 기본은 AI가 계속 스스로 싸웁니다**(자동 이동 + 자동 공격). **유저가 이동 입력(조이스틱 드래그 / WASD·화살표)을 하는 동안에만** 이동이 수동으로 오버라이드되고, 입력을 멈추면 0.5초 뒤 AI 이동이 재개됩니다. 자동 공격은 수동 이동 중에도 항상 유지됩니다.
  - 영웅도 병사와 같은 교전 AI로 스스로 전장에서 싸웁니다. 조작하던 유닛이 죽으면 자동으로 **영웅에게 조작이 복귀**하며, 데스크톱에서는 **Tab** 키로 언제든 영웅으로 돌아옵니다.
  - 액티브 스킬 "일섬"(주변 원형 AOE)은 **영웅에 빙의 중 + MP가 충분할 때만**(MP 30 소모) 사용할 수 있습니다. MP가 부족하면 버튼이 비활성화됩니다.
  - **폭열검**: 영웅의 기본 무기. 근접 타격 시 10% 확률로 타격 지점에 폭발 마법이 터져 반경 내 적에게 AOE 피해(주황 대미지 숫자) + 화염 이펙트 + 짧은 화면 흔들림을 일으킵니다.
- **조작**
  - 모바일: 화면 **왼쪽**을 드래그하면 플로팅 조이스틱으로 이동, **오른쪽 하단** 버튼으로 스킬, 유닛 **탭**으로 빙의/정보.
  - 데스크톱: **WASD / 화살표** 이동, **스페이스바** 스킬, 유닛 **클릭** 빙의/정보, **Tab** 영웅 복귀.

> **전략층(예정)**: 부대는 향후 거점 이동 턴제 전략층에서 "이동 단위"로 재사용될 예정이며, 이번 슬라이스는 그 전략층 아래에서 벌어지는 **야전 한 판**의 질에 집중합니다.

## 기술 스택

- Phaser 3 + TypeScript + Vite
- 외부 이미지/오디오 에셋 **0개** — 모든 스프라이트(유닛·배너·데코·이펙트·링)는 논리 픽셀 그리드에 손으로 배치한 뒤 실루엣 자동 외곽선 + 명암 2단계로 그려 런타임 텍스처로 등록합니다 (`src/gen/spriteGen.ts`). 유닛마다 걷기 2 + 공격 1 + 시체 1 프레임.
- Arcade Physics. 85+ 유닛 동시 밀집 전투를 위해 그리드 기반 타겟 탐색 + 그리드 기반 분리(separation) 스티어링 + 스태거드 AI 틱(프레임 분산) + 투사체/이펙트 오브젝트 풀링 + HP바 배치 렌더를 사용합니다.

## 로컬 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173/make/)
npm run build    # 타입체크 + 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```

## GitHub Pages 배포

이 저장소에는 `.github/workflows/deploy.yml` 이 포함되어 있습니다. `main` 브랜치에 push하면 자동으로 빌드 후 Pages에 배포됩니다.

워크플로의 deploy 잡이 `actions/configure-pages@v4` (`enablement: true`) 로 Pages 사이트를 **자동 생성/활성화**하므로, 저장소 설정에서 별도로 Pages를 켜지 않아도 첫 배포부터 동작합니다.

1. `main` 브랜치에 push (또는 Actions 탭에서 `workflow_dispatch` 로 수동 실행)
2. 배포 완료 후 `https://<사용자명>.github.io/make/` 에서 플레이

> `vite.config.ts` 의 `base: '/make/'` 는 프로젝트 페이지 경로(`/make/`)에 맞춘 값입니다. 저장소 이름이 다르면 이 값을 함께 바꿔야 합니다.

## 프로젝트 구조

```
src/
  main.ts              # Phaser 게임 부트스트랩
  config.ts            # 모든 밸런스 수치 + 탭(빙의) 판정 상수
  gen/spriteGen.ts     # 절차 생성 스프라이트 (유닛·배너·데코·이펙트·링)
  scenes/
    BootScene.ts       # 부대별 병종 텍스처 등 전체 텍스처 생성
    TitleScene.ts      # 타이틀 + 시작 버튼
    BattleScene.ts     # 야전 로직 (부대 편성·대형·AI·분리 스티어링·승패·빙의·정보 선택)
    UIScene.ts         # 상단 요약 + 하단 정보창 + 스킬버튼 + 결과 오버레이
  rpg/
    stats.ts           # 최종 스탯 계산 (직업 base + 레벨 성장 + 장비) + EXP 테이블 조회
    items.ts           # 부위별 장비 6슬롯 · 아이템 정의 · 병종 기본 세트 · 스탯 보정 합산
    skills.ts          # 장비 proc 스킬 (폭열검=폭발, 금강저=스턴+넉백) — 범용 { chance, effect } 구조
  units/
    Unit.ts            # 유닛 기반 클래스 (스탯·레벨업·장비·피격/방어·넉백·분리·공용 전투 루틴·하이브리드 조작)
    Hero.ts            # 영웅 (교전 AI + 빙의 + 일섬 스킬 MP 소모)
    Soldier.ts         # 아군 병사 (검병/궁병/창병)
    Monster.ts         # 적 (고블린/고블린 궁수/오니)
    Projectile.ts      # 화살 투사체 (곡사 + 그림자, 풀링)
  world/
    MapGen.ts          # 손 설계 평원 전장 배경 + 데코(숲·바위·덤불) 배치
  input/
    FloatingStick.ts   # 모바일 플로팅 조이스틱
```

부대 편성은 `config.ts` 의 `SQUADS` 배열에 정의되어 있으며, 향후 전략층에서 그대로 재사용할 수 있도록 타입(`SquadDef`)으로 모델링되어 있습니다.

## 알려진 한계 (이번 슬라이스 범위 밖)

- 사운드, 세이브, 캠페인, 거점 이동 전략층은 아직 없음(전략층은 예정).
- 빙의는 아군 개별 유닛에만 가능하며, 부대 단위 명령(집결·돌격 지정 등)은 아직 없습니다.
- 장비 착탈/인벤토리 UI와 전직(직업 변경)은 마을 층(예정)의 몫이며, 이번 슬라이스는 기본 장비가 스탯에 반영되고 정보창에 표시되는 데까지입니다. MP 자동 회복은 아직 없습니다.
